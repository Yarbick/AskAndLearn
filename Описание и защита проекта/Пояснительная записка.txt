Название проекта: Ask&Learn (AskAndLearn)
Создатель проекта: Ярбилов Ильяс Робертович
Идея: Форум для публикации вопросов Ask&Learn (или же AskAndLearn). Пользователи могут задавать вопросы, отвечать на них, отмечать их как избранные. Есть возможность добавлять в друзья или же блокировать других людей. Если автору вопроса подошёл ответ, то он может отметить выбранный комментарий «полезным» и отметить вопрос решённым. Также можно закрыть вопрос

      Flask-Talisman
      SQLAlchemy
      SQLAlchemy-Serializer
      Flask-RESTful
      Requests

      imghdr
      re
      Jinja2
    Применённые технологии (по критериям оценивания проекта)

  Структура:
      В проекте применяется монолитно-модульная архитектура с некоторыми идеями микросервисов
      Приложение делится на узлы. Узлы связывают разные модули, которые объединены по определённым признакам (в основе смысл и общая
    БД). Каждый модуль выполняет свою определённую функцию, которая не зависит от других модулей. Модуль хранит в себе обработчики,
    формы, шаблоны, статические файлы, API и т. д. (комплектация зависит от функционала). Модули общаются друг с другом через REST API

  Данные:
      Для хранения данных применяется БД SQLite 
      Управление БД происходит через ORM. В качестве ORM используется библиотека SQLAlchemy с надстройкой SQLAlchemy-Serializer для
    превращения данных в словари
      В проекте присутствует 2-е базы данных: user (таблицы: user, friendship), qa (таблицы: question, tag, tag_to_question, favorite,
    comment)
      Применяются разнообразные связи между таблицами: один-к-многим, многие-к-многим и т. д.

  API:
      Как говорилось ранее, для общения модулей применяется REST API
      Приложение использует надстройку для Flask – Flask-RESTful, которое позволяет создавать собственные API ресурсы. Для обращения к
    своему REST API применяется библиотека Requests
      Каждый API имеет свои валидаторы, парсеры, ресурсы
      API построено на основе принципов REST

  Cookie:
      Для регистрации и авторизации пользователя используется надстройка для Flask – Flask-Login. Она сохраняет данные о пользователе в
    Cookie
      Также применяется ручная работа с Cookie через специальные объекты Flask – Session (Сессии). Через них сохраняется история о 
    посещении последних вопросов, которые отображаются в меню

  Frontend:
      Для визуальной (CSS/JavaScript) части приложения применяется фреймворк Bootstrap. Некоторые стили написаны вручную
      HTML написан вручную с использованием шаблонизатора Jinja2 для взаимодействия сервера с шаблонами
      Также применяются формы для ввода данных из библиотек WTForms и Flask-WTF

  Безопасность:
      Приложение предусматривает защиту от CSRF-атак через встроенные средства Flask-WTF
      Предусмотрена защита от XSS-атак при помощи библиотеки Bleach
      Настроена система против СПАМ атак (например, DDOS, Brute-Force) через лимиты на обработчики и API-endpoints через надстройку 
    Flask – Flask-Limiter
      Загрузка изображений проходит через проверку имени, MIME-типа и расширения файла

  Хостинг:
      Применяется WSGI сервер Waitress
      Хостинг проекта осуществляется через сервис localhost.run (бесплатный тариф). В качестве сервера используется собственный компьютер
      Также предусмотрен запуск через локальный хостинг (127.0.0.1)
       Полная инструкция о запуске находится в файле README.txt
