<--Описание-->
Веб-приложение AskAndLearn, которое является площадкой для публикации вопросов и получения на них ответов.
Учебный проект для Яндекс Лицея.

<--Зависимости-->
Программа работает на языке Python (3.12 и выше)
Все необходимые библиотеки находятся в файле requirements.txt

<--Инструкция по установке-->
На Windows:
  1. Клонируйте проект с GitHub по ссылке: https://github.com/Yarbick/AskAndLearn.git
  2. Установите компилятор Python
  3. Зайдите в cmd в папке с проектом и пропишите команду (установка зависимостей):
      pip install -r requirements.txt

Теперь у вас есть готовое приложение

<--Инструкция по запуску-->
1. Запустите файл start_app.sh (запуск приложения)
2. Запустите хостинг (приложение можно протестировать без хостинга, он будет на локальном хосте http://127.0.0.1:5000):
  A. Для хостинга на сервисе localhost.run требуется SSH ключ:
       1. Его следует создать командой в терминале (может зависеть от ОС, данный пример работает на Windows): ssh-keygen -t rsa -b 2048
       2. Далее, после создания SSH ключа, его следует найти (путь к файлу выбирался при создании ключа) и выбрать публичный ключ (у него будет расширение .pub)
       3. Копируем ключ (весь файл полностью)
       4. Заходим на сайт https:/admin.localhost.run (может потребоваться VPN)
       5. Регистрируемся на сайте
       6. Заходим во вкладку SSH-keys (или подобное название)
       7. Создаём новый ключ: в описание можно ввести что угодно, а во второе поле наш скопированный ключ
       8. Поздравляем! Вы создали ключ
       9. Запустите файл start_hosting.sh (запуск хостинга) и введите пароль для ключа (если вы его указывали)
       10. В результате должно появиться сообщение с ссылкой и QR-кодом
  B. Если вы не хотите создавать ключ, то можете запустить хостинг анонимно (менее стабильно):
       1. В файле start_hosting.sh меняем 5-ую строчку:
            Изначально в файле: ssh -R 80:127.0.0.1:5000 localhost.run
            Требуется изменить на: ssh -R 80:127.0.0.1:5000 nokey@localhost.run
       2. Запустите файл start_hosting.sh
       3. В результате должно появиться сообщение с ссылкой и QR-кодом

!!! Следует учесть, что хостинг бесплатный, а это значит, что он довольно слабый и нестабильный, если вы проверяющий проекта, то лучше проводить операции через локальный хостинг !!!
